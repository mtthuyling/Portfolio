PORTFOLIO MAI LINH — HTML5 + CSS3 THUẦN

Cấu trúc:
- index.html : Trang Portfolio cho nhà tuyển dụng
- login.html : Giao diện đăng nhập
- admin.html : Giao diện Dashboard quản trị (dữ liệu mẫu)
- style.css  : CSS dùng chung, có CSS Variables, Flexbox, Grid, responsive

Cách chạy:
1. Giải nén file ZIP.
2. Mở thư mục bằng VS Code.
3. Mở index.html bằng trình duyệt hoặc dùng Live Server.
4. Vào Login qua nút “Khu vực quản trị” hoặc “Admin login” ở chân trang.

Lưu ý quan trọng:
- Bài yêu cầu HTML5 + CSS3 thuần, không dùng JavaScript/framework nên Login và Dashboard hiện là giao diện tĩnh.
- Form login chuyển sang admin.html để minh họa luồng giao diện; chưa xác thực username/password.
- Các nút thêm/sửa/lọc trong dashboard là mẫu giao diện, chưa lưu hay thay đổi dữ liệu thật.
- Để có đăng nhập bảo mật và quản lý dữ liệu thực sự cần backend/cơ sở dữ liệu hoặc JavaScript, nằm ngoài phạm vi HTML/CSS thuần.
- Hãy thay tên, email, kỹ năng và mô tả dự án cho khớp thông tin thật của bạn trước khi nộp.
